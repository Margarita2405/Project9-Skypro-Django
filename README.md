# SkyStore — интернет-магазин товаров для дома и офиса

Проект интернет-магазина на Django для продажи электроники, игрушек, одежды, косметики, товаров для спорта,
дома и сада.

## 📋 Описание

SkyStore — это веб-приложение, позволяющее пользователям просматривать каталог товаров, читать публикации в блоге
и совершать покупки.

## 🚀 Функциональность

*   **Главная страница** (`home.html`)
*   **Каталог:** Товары, категории, детальная информация.
*   **Контакты:** Реквизиты, обратная связь.
*   **Пользователи:** Email-авторизация, профиль.
*   **Блог:** Публикации, просмотры.
*   **Админка:** Управление контентом через Django Admin.


## 🛠️ Технологии

- **Python** 3.13+
- **Django** 
- **PostgreSQL**
- **HTML5** / **CSS3** (Bootstrap 5 для стилизации)
- **Poetry** — управление зависимостями

## Установка и запуск

### 1. Клонирование репозитория

```
git clone https://github.com/Margarita2405/Project9-Skypro-Django
cd Project9-Skypro-Django
```

### 2. Установка зависимостей (через Poetry)
```
poetry install
```

Или через pip (если нет Poetry):
```
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Скопируйте .env.example в .env и заполните необходимые значения:

```
cp config/.env.example config/.env
```

Пример содержимого .env:

```
SECRET_KEY=your-secret-key-here
DEBUG=True
ALLOWED_HOSTS=127.0.0.1,localhost
```
# Настройки базы данных (укажите свои при использовании PostgreSQL)
```
DATABASE_NAME=skystore
DATABASE_USER=postgres
DATABASE_PASSWORD=your_password
DATABASE_HOST=localhost
DATABASE_PORT=5432
```

### 4. Подготовка базы данных

Выполните применение миграций и создайте учетную запись администратора:

# Применение миграций ко всем приложениям
```
python manage.py migrate
```

# Создание суперпользователя для доступа к админ-панели
```
python manage.py createsuperuser
```

### 5. Запуск сервера разработки

```
python manage.py runserver
```
Приложение будет доступно по адресу: http://127.0.0.1:8000


## Доступные страницы
| URL | Страница |
| `/catalog/` | Главная страница интернет-магазина (`home.html`) |
| `/catalog/products/` | Страница каталога товаров (`contacts.html`) |
| `/catalog/contacts/` | Страница контактов (`contacts.html`) |
| `/users/` | Страница регистрации и профиля пользователя |
| `/blogs/` | Лента публикаций блога |
| `/admin/` | Административная панель Django |

## Используемые стили
Проект использует фреймворк Bootstrap 5 (подключается через CDN). Для кастомных стилей создана директория config/static/.
